# Israeli Political Leadership Accountability Library

Evidence-first library of documented statements, decisions, governance/management failures, conflicts, legal/ethical issues and personal conduct involving prominent Israeli political leaders.

Architecture:
- Google Sheets = canonical event/source/media data
- Notion = visual searchable gallery
- GitHub = stable exact-media preview cache and research process

The library records evidence and outcomes. It does not presume a global judgment about a person's leadership ability, guilt, motive or ideology.
