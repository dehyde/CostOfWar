# Channel 14 Fact-Check Library

Evidence-first library of materially false, misleading, unsupported, outdated or context-deficient factual claims broadcast or published by Channel 14.

Architecture:
- Google Sheets = canonical claim/source/media data
- Notion = visual searchable gallery
- GitHub = stable exact-media preview cache and research process

A social-media post alone is never sufficient counter-evidence. Preserve the original Channel 14 media and separately document the strongest credible evidence that corrects or contradicts the claim.
